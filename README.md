# PRISM

PRISM is a molecular representation learning framework that uses traditional chemical descriptors and fingerprints as **prior-defined similarity geometries**. Instead of treating descriptors only as input features, PRISM uses them to define relational supervision over molecules and pre-trains graph encoders to preserve these prior-induced neighborhood structures.

The framework contains three main stages:

1. **Chemical space construction**: build descriptor-induced prior spaces.
2. **Prior-alignment pre-training**: align molecular graph embeddings with prior-defined similarity geometries.
3. **Downstream fine-tuning**: evaluate the learned representations on single-molecule prediction and solute–solvent–temperature solubility regression.

The graph encoder follows a MPNN-style message passing architecture adapted from Chemprop.

---

## Repository Structure

```text
PRISM/
  chemprop/           # Lightweight Chemprop/CMPNN components
  data/               # Single-molecule datasets, e.g., MoleculeNet-style CSVs
  model/              # PRISM encoders, fusion heads, and losses
  pair_data/          # Solute–solvent–temperature solubility datasets

  pretrain.py         # Prior-alignment pre-training
  finetune_single.py  # Single-molecule fine-tuning
  finetune_pair.py    # Pure-solvent solubility fine-tuning
  finetune_mix.py     # Mixed-solvent solubility fine-tuning

  requirements.txt
  README.md
```

Generated folders such as `ckpt/`, `results/`, and run logs are created by the scripts through `--save_dir` or `--out_dir`.

Large checkpoints, intermediate files, and raw datasets should not be committed unless they are intended for public release.

## Data

### 1. Single-Molecule Datasets

Single-molecule datasets are stored under `data/`.

They are typically MoleculeNet-style CSV files with the following fields:

```text
smiles,label
CCO,0.12
...
```

For classification datasets, the label column contains binary or multi-task labels.  
For regression datasets, the label column contains continuous molecular properties.

Depending on the dataset, split information may be stored either inside the CSV or generated by the fine-tuning script.

---

### 2. Pair-Wise Solubility Datasets

Pair-wise solubility datasets are stored under `pair_data/`.

These datasets contain solute–solvent–temperature regression samples, for example BigSolDB-derived training data and external test sets such as Leeds or SolProp.

A typical CSV contains:

```text
solute_smiles,solvent_smiles,temperature,logS
CCO,O,298.15,-1.23
...
```

Column names may vary depending on the preprocessing pipeline. Please check the script arguments with:

```bash
python finetune_pair.py --help
python finetune_mix.py --help
```

If some datasets cannot be redistributed, we recommend releasing:

1. the preprocessing scripts;
2. the train/validation/test split files;
3. instructions for reconstructing the datasets from public sources.

## Usage

All main scripts support command-line help:

```bash
python pretrain.py --help
python finetune_single.py --help
python finetune_pair.py --help
python finetune_mix.py --help
```

## 1. Prior-Alignment Pre-Training

PRISM first pre-trains prior-specific graph encoder branches by aligning molecular embeddings with descriptor-induced similarity geometries.

Example:

```bash
python pretrain.py \
  --vsa_csv ./data/vsa_zinc_25k.csv \
  --tau 0.1 \
  --tau_phys_scale 0.25 \
  --save_dir ./ckpt/tau_0.1__scale_0.25
```

Expected outputs:

```text
ckpt/tau_0.1__scale_0.25/
  task_0/
    best_model.pth
  task_1/
    best_model.pth
  task_2/
    best_model.pth
  task_none/
    best_model.pth
```

The exact checkpoint structure may vary depending on the number of prior spaces used in pre-training.

## 2. Single-Molecule Fine-Tuning

Use `finetune_single.py` for MoleculeNet-style classification or regression tasks.

Example: BBBP classification with multiple pre-trained branches and weighted fusion.

```bash
python finetune_single.py \
  --dataset bbbp \
  --encoder_ckpts \
    ckpt/tau_0.1__scale_0.25/task_0/best_model.pth,\
    ckpt/tau_0.1__scale_0.25/task_1/best_model.pth,\
    ckpt/tau_0.1__scale_0.25/task_2/best_model.pth,\
    ckpt/tau_0.1__scale_0.25/task_none/best_model.pth \
  --space_indices 0,1,2,3 \
  --seeds 42,43,44 \
  --batch_size 64 \
  --epochs 200 \
  --learning_rate 1e-4 \
  --dropout 0.3 \
  --weight_decay 0.0 \
  --out_dir results/single_bbbp
```

Outputs include validation/test metrics and a summary file under `--out_dir`.

Typical metrics:

- ROC-AUC for classification tasks;
- RMSE or MAE for regression tasks.

## 3. Pure-Solvent Solubility Fine-Tuning

Use `finetune_pair.py` for solute–solvent–temperature solubility regression.

Example: train on a BigSolDB-style dataset and evaluate on Leeds and SolProp.

```bash
python finetune_pair.py \
  --train_csv pair_data/bigsoldb_chemprop_nonaq.csv \
  --test_csvs pair_data/leeds_all_chemprop.csv,pair_data/solprop_chemprop_nonaq.csv \
  --encoder_ckpts \
    ckpt/tau_0.1__scale_0.25/task_0/best_model.pth,\
    ckpt/tau_0.1__scale_0.25/task_1/best_model.pth,\
    ckpt/tau_0.1__scale_0.25/task_2/best_model.pth,\
    ckpt/tau_0.1__scale_0.25/task_none/best_model.pth \
  --space_indices 0,1,2,3 \
  --seeds 42,43,44 \
  --batch_size 64 \
  --epochs 200 \
  --val_ratio 0.05 \
  --learning_rate 1e-4 \
  --weight_decay 0.0 \
  --solute_dropout 0.3 \
  --solvent_dropout 0.3 \
  --mlp_hidden 1024,128,64 \
  --mlp_dropout 0.2 \
  --t_embed_dim 32 \
  --out_dir results/pair_solvation
```

Reported metrics include:

- RMSE;
- percentage of predictions with absolute error no larger than 1 log unit, denoted as `% |ΔlogS| ≤ 1`.

## 4. Mixed-Solvent Solubility Fine-Tuning

Use `finetune_mix.py` for mixed-solvent solubility prediction.

Because mixed-solvent datasets may use different column names and mixture representations, please first check:

```bash
python finetune_mix.py --help
```

Typical mixed-solvent inputs include:

```text
solute_smiles,solvent1_smiles,solvent2_smiles,ratio1,ratio2,temperature,logS
...
```

The training command generally follows the same structure as `finetune_pair.py`, with additional arguments for solvent composition and mixture-specific settings.

## Reproducibility

For reproducible experiments, we recommend:

1. fixing random seeds with `--seeds`;
2. reporting mean ± standard deviation over multiple runs;
3. saving the full command-line configuration for each run;
4. keeping all split files under version control;
5. logging the git commit hash for each experiment;
6. using identical splits when comparing different models.

Example:

```bash
python finetune_single.py \
  --dataset bbbp \
  --seeds 42,43,44 \
  --out_dir results/single_bbbp
```
